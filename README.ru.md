# AI Chat Buttons

Универсальные кнопки промтов для веб-интерфейсов AI чатов. Предоставляет настраиваемые кнопки промтов на множестве AI платформ.

## Версия
0.0.1

## Поддерживаемые платформы
- OpenAI (ChatGPT)
- Claude (Anthropic)
- DeepSeek
- Qwen (Tongyi)
- Grok (X)
- Google Gemini
- Microsoft Copilot
- Kimi
- DuckDuckGo
- Mistral
- Hugging Face
- Perplexity
- Poe
- Pi
- Phind
- You.com

## Возможности
- Настраиваемые кнопки промтов
- Организация по категориям
- Контроль размера и прозрачности панели
- Наборы кнопок для каждой платформы
- Встроенные промты для аудита
- Портативное управление состоянием

## Установка
1. Установите Tampermonkey или аналогичный менеджер userscript
2. Откройте этот репозиторий
3. Нажмите на `AICHATBUTTONS.js`
4. Tampermonkey предложит установить скрипт
5. Подтвердите установку

## Использование
- Скрипт автоматически загружается на поддерживаемых страницах AI чатов
- Доступ к панели кнопок через интерфейс
- Настройка кнопок и категорий через настройки
- Используйте встроенные промты или создайте свои

## Конфигурация
Кнопки и настройки хранятся локально в браузере. Скрипт предоставляет интерфейс конфигурации для:
- Добавления/редактирования кнопок промтов
- Создания категорий
- Настройки внешнего вида панели
- Управления наборами кнопок для каждой платформы

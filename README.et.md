# AI Chat Buttons

Universaalne AI promptide nuppude süsteem veebi-põhiste AI vestluste liidestele. Pakub kohandatavaid promptide nuppe mitmel AI platvormil.

## Versioon
0.0.1

## Toetatud platvormid
- OpenAI (ChatGPT)
- Claude (Anthropic)
- DeepSeek
- Qwen (Tongyi)
- Grok (X)
- Google Gemini
- Microsoft Copilot
- Kimi
- DuckDuckGo
- Mistral
- Hugging Face
- Perplexity
- Poe
- Pi
- Phind
- You.com

## Funktsioonid
- Kohandatavad promptide nupud
- Kategooriate organiseerimine
- Paneeli suuruse ja läbipaistvuse juhtimine
- Nuppude komplektid iga platvormi jaoks
- Sisseehitatud auditide promptid
- Pordatav oleku haldus

## Installimine
1. Installige Tampermonkey või sarnane userscripti haldur
2. Avage see repopositoorium
3. Klõpsake `AICHATBUTTONS.js` failil
4. Tampermonkey pakub skripti installimist
5. Kinnitage installimine

## Kasutamine
- Skript laaditakse automaatselt toetatud AI vestluslehtedel
- Juurdepääs nuppude paneelile liidese kaudu
- Nuppude ja kategooriate kohandamine seadete kaudu
- Kasutage sisseehitatud prompte või looge oma

## Konfiguratsioon
Nupud ja seaded salvestatakse kohalikult brauseris. Skript pakub konfiguratsiooni liidest:
- Promptide nuppude lisamine/redigeerimine
- Kategooriate loomine
- Paneeli välimuse seadistamine
- Nuppude komplektide haldamine iga platvormi jaoks
